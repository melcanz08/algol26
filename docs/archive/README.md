# Archived Documentation

Files in this directory describe an earlier state of the codebase.
They are kept for historical context and reference, not as current
documentation.

Every file in this directory should begin with an ARCHIVED banner:

    > **ARCHIVED — <date>**
    >
    > This document was accurate at the time it was written. It
    > describes an earlier state of the codebase and may reference
    > modules or behaviors that no longer exist. Do not rely on it
    > for current behavior.
    >
    > Current documentation: see `docs/README.md`.

Do not edit archived files to update them. If a decision in an
archived file is still binding, copy it forward into a current
document or into a new ADR in `docs/decisions/`.
